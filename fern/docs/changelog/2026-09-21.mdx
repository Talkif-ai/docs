---
title: "Web call hangup and billing reliability fixes"
---

{/* versions: backend=0.1.209 frontend=0.1.37 catflow=0.0.81-rc.12 */}

- **Calls**: Ending a web call now takes effect immediately instead of waiting for the connection to time out. See [Browser SDK](/sdks/browser).
- **Account**: Adding your first phone number no longer requires setting a password — useful if you signed up with Google. See [Security](/account/security).
- **Billing**: Low-balance notifications are far less frequent, and accounts that have never added funds no longer get a false "balance depleted" warning. See [Notifications](/account/notifications).
- **Billing**: A phone number's monthly rental now recovers correctly after a temporary payment failure — topping up reliably reactivates a past-due number instead of leaving it stuck. See [Buy a number](/telephony/buy-a-number#what-happens-when-rental-cant-be-paid).
- **Builder**: The AI assistant keeps one continuous conversation as you move between the dashboard and the flow canvas, instead of starting over. See [Assistant](/build/assistant).
