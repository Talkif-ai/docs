---
title: Your First Call
description: Step-by-step guide to building a flow, assigning it to a phone number, and making your first AI voice call.
---

This walkthrough takes you from zero to a live AI voice call. You'll purchase a number, build a flow, and test it.

## 1. Purchase a phone number

1. Navigate to **Phone Numbers** in the sidebar
2. Click **Purchase Number**
3. Search by area code or region
4. Select a number and confirm the purchase

## 2. Create a new flow

1. Navigate to **Flow Builder** in the sidebar
2. Click **New Flow**
3. Give your flow a name (e.g., "Customer Support Agent")

The builder opens with a **Main Agent** node already placed on the canvas.

## 3. Configure the Main Agent

1. Click the **Main Agent** node to open its settings
2. Set the **System Prompt** — define who the agent is (e.g., "You are a friendly customer support agent for Acme Corp.")
3. Set the **Task Prompt** — define what it should do (e.g., "Help callers with account questions. If you can't resolve an issue, collect their email and let them know a human will follow up.")

<Info>
  The system prompt sets personality and boundaries. The task prompt sets the objective. Keep both clear and specific.
</Info>

## 4. Add provider nodes

Drag these nodes onto the canvas and connect them to the Main Agent:

1. **LLM Node** — select a language model (e.g., GPT-4o)
2. **TTS Node** — select a text-to-speech provider (e.g., ElevenLabs) and choose a voice
3. **STT Node** — select a speech-to-text provider (e.g., Deepgram)

<Warning>
  A flow requires all three provider types (LLM + TTS + STT) to publish. The system will block publishing if any are missing.
</Warning>

## 5. Publish the flow

1. Click **Publish** in the top-right corner
2. The system validates your flow — it checks for a Main Agent and all three provider nodes
3. Once validated, the flow is published and ready for assignment

## 6. Assign the flow to your phone number

1. Navigate to **Phone Numbers** in the sidebar
2. Click on the number you purchased
3. Under **Assigned Flow**, select your published flow
4. Save the configuration

## 7. Make a test call

You have two options:

- **Call from your phone** — dial the number you purchased and talk to your agent
- **Quick Call** — go to **Call Center** and use the Quick Call feature to initiate a call directly from the platform

## 8. Review the call

1. Navigate to **Call Center** in the sidebar
2. Find your call in the list and click on it
3. Review the full **transcript**, listen to the **recording**, and check the **cost breakdown**

<Info>
  The cost breakdown shows exactly how credits were used — LLM tokens, TTS characters, and STT duration — so you can optimize provider choices over time.
</Info>
