Talkif uses a pay-as-you-go credits model. No subscriptions, no tiers — purchase credits and use them for calls.

## How it works

1. **Purchase credits** — add funds to your account balance
2. **Use credits** — costs are deducted in real-time as calls run
3. **Stay topped up** — enable auto-recharge so you never run out mid-call

Every call provides a full cost breakdown so you always know exactly where your credits go.
