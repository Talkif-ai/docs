Every call on Talkif produces a detailed cost breakdown so you know exactly what you're paying for.

## Per-call cost categories

Each call's total cost is split into these categories:

| Category | What it covers |
|---|---|
| **LLM Conversation** | Language model token usage during the call |
| **LLM Analysis** | Post-call AI analysis (separate line item) |
| **STT** | Speech-to-text transcription processing |
| **TTS** | Text-to-speech audio generation |
| **Telephony** | Voice minutes and connection fees. [WhatsApp calls](/phone-numbers/whatsapp) carry no telephony charge — Meta bills you directly; all other categories apply normally |
| **Infrastructure** | Platform compute and media relay costs |
| **Function Call** | External function/tool call execution during the call |

The cost trend view in analytics groups these into four high-level categories: LLM (conversation + analysis), STT, TTS, and Telephony.

The cost breakdown is visible on every call's detail page in the Call Center.

## Viewing cost trends

The dashboard provides cost charts with period comparison:

- **Today** — current day's spending
- **This week** — rolling 7-day view
- **This month** — current billing period

Use these to track spending patterns and identify cost drivers across your call volume.
