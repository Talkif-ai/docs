Once a flow is published and on a number, running calls is operations: deciding who gets called, when, from which line, and then reading what happened. Talkif gives you three ways to start outbound calls and one place to read the results, all sharing the same contacts and the same Do Not Call list.

| Way to start | Good for | Set up in |
|---|---|---|
| **Single call** | Testing, one-off callbacks, calls triggered by your own systems | Dashboard **Start a call**, or `POST /calls` |
| **Campaign** | A list of contacts, called with pacing, windows, retries and analytics | **Call Center → Campaigns** |
| **Schedule** | One contact, called on a recurrence — daily check-ins, monthly reminders | **Call Center → Schedules** |

Inbound calls need nothing here; they're handled by the flow connected to the number ([Telephony](/telephony)).
