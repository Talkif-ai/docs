The Call Center is your operational hub for all voice activity. Make quick calls, run large-scale campaigns, review transcripts, and manage business hours — all from the Talkif dashboard.

## Core capabilities

| Feature | Description |
|---|---|
| **Quick calls** | Make one-off inbound or outbound test and live calls |
| **Campaigns** | Run automated outbound call campaigns across contact lists |
| **Call details** | Review transcripts, recordings, cost breakdowns, and metadata for every call |
| **Schedules** | Define business hours, timezones, and holidays to control when calls happen |

## How it fits together

1. **Build a flow** in the [Flow Builder](/flow-builder) and publish it
2. **Assign the flow** to a [phone number](/phone-numbers)
3. **Make calls** — either one-off quick calls or automated campaigns
4. **Review results** in call details with full transcripts and recordings
